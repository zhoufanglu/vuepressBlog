    vite

    lufangzhou 1/26/2021 vue

    # 介绍

    • 尤于溪的原话。
    • vite与Vue CLI 类似，vite也是一个提供基本项目脚手架和开发服务器的构建工具。
    • vite基于浏览器原生ES imports的开发服务器。跳过打包这个概念，服务端按需编译返回。
    • vite速度比webpack快10+倍，支持热跟新， 但是出于处于测试阶段。
    • 配置文件也支持热跟新！！！

    # 创建

    执行npm init @vitejs/app ，我这里选择的是vue-ts

    routes: routes
