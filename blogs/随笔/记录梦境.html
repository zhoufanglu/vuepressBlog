    个人梦境录

    lufangzhou 11/17/2024 随笔
    • 记录当天晚上做的梦，万一发现连起来是有规律的呢？哈哈哈，说不定能搞到好多钱。

    # 2025-12-03

    • 昨天梦到和同事zyd一起去新加坡了，离谱的一逼，他还买了大疆 action， 一起拍了照片， 见到了狮头鱼尾喷泉，然后跟冒险岛里面一样，一起发了朋友圈。

    # 2025-09-19

    • 先是梦到了安安，她在一个村庄里， 好像嫁给了一个平凡的男人， 但是她并不开心。然后我每天都去她，想把她带走。但是她后面不愿意了。
    • 梦到我父亲炒币，挣了1000多万，换了特斯拉 performance, 但是汽车后面会喷火。。。后面我父亲带我花天酒地，最后把家玩破产了。。 然后我父亲又开始炒币，后面我求他不要炒，最后把房子卖了，家破人亡。

    # 2025-09-16

    • 这次的梦很开心，开了一家小小的面馆。
    • 里面装修的很卡通，一个一个卡座，有点像深夜食堂，既适合情侣，也适合一个人安静坐下来。
    • 面条是简单的泡面，不为赚多少钱，只希望能和来店的客人聊聊天，分享一些温度。。
    • 然后这家面馆名字叫"我们的面馆"，嘻嘻。
    • 而最特别的是，这家面馆就开在我和安安第一次见面的那条街上。💫

    # 2025-09-15

    • 不太记得了， 奶奶去世了。。我好像哭了， 好像又没有哭。。
    • 奶奶去世前，自己去理发店，把头发染黑了。

    # 2025-08-26

    昨天梦到了，我把安安带回家了，然后带她去了新家，跟父亲吵架了，因为父亲要跟着我去。

    # 2025-08-05

    奇怪的发生了三段梦。
    1、我好像去了大海里，见到了鲸鱼，用我的iwatch拍下了视频（实际上iwatch并不能拍视频），最后还看到了旋涡，然后跟朋友一起玩了海上足球。
    2、我是一名忍者，我有一辆摩托车，我可以在墙上行驶（siguoyi~）， 轮子还能展开，特别炫酷。然后我1打4，把别的忍者打穿了，很帅。
    3、还有一段，我不记得了。我印象中是还有一段的。

    # 2025-07-03

    昨晚梦到了我有了辆小米su7， 感觉好爽，ngp，自动驾驶都很流畅。 我中途换了导航，直接可以自动给我掉头(不知道现在能不能做到那种效果)

    # 2024-01-17

    又梦到她了，她的朋友劝我不要跟他在一起，哭了，她。

    # 2024-01-16

    昨天梦到领导考察我题目，判断字符串是否是中文，但是梦里实在提不起笔，还有个梦，忘记了。

    # 2022-11-10

    好久没记录了，昨天晚上梦到带许涵翊和卢敏旭一起玩冒险岛，那感觉真的好，虽然梦境不跟我一起走，但是真的那喜欢那种感觉。

    # 2021-9-28

    梦到东东大学室友，真的好奇怪，一个小胖子，一个像后舍男孩的人（在上海当老师），厉害的人在上海厉害，不厉害的也不厉害。

    # 2021-8-6
